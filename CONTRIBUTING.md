# Contributing

This repository is currently maintained as a research project.

Before opening a pull request:

1. keep experiments reproducible,
2. preserve deterministic scenario seeds where applicable,
3. add or update validation checks,
4. avoid changing previously frozen experiment definitions without documenting the change,
5. keep scientific claims separate from validation/integrity checks.

For changes that alter the estimator, fault model, or experiment design, document:

- what changed,
- why it changed,
- which frozen results become non-comparable,
- whether new baselines are required.
